# Articles

Article files live here as `descriptive-slug.mdx`. Nothing is published while
`draft` is `true`.

```mdx
---
title: Approved article title
summary: Approved article summary
published: YYYY-MM-DD
tags:
  - AI
draft: true
---

# Approved article title

Write the article here.
```

Markdown tables, task lists, footnotes, code fences, inline and display math are
supported. Use `$...$` for inline math and `$$...$$` for display math. Citations
can be written as linked references or footnotes.
